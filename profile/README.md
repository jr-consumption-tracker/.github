# 📊 Consumption Tracker

> Personal utility consumption tracking and analytics platform

Track, analyze, and optimize your household consumption - electricity, water, gas, and more.

## 🎯 What is this?

A modern web application for monitoring and managing utility consumption data. Built to help understand usage patterns, identify savings opportunities, and maintain historical records.

## 🏗️ Projects

### [consumption-api](https://github.com/jr-consumption-tracker/consumption-api)
RESTful API backend built with PHP 8.3+ and MySQL. Handles all data processing, storage, and business logic.

### [consumption-web](https://github.com/jr-consumption-tracker/consumption-web)
Modern frontend monorepo with React/Next.js. Includes both the user interface and admin dashboard.

## ✨ Features

- 📈 Track multiple consumption types (electricity, water, gas)
- 📊 Visualize usage patterns and trends
- 💡 Identify optimization opportunities
- 📱 Responsive design for desktop and mobile
- 🔐 Secure data management
- 📅 Historical data tracking

## 🚀 Tech Stack

**Backend:** PHP 8.3, MySQL, Docker  
**Frontend:** React, Next.js, TypeScript  
**Tools:** Turborepo/Nx, Composer
